<img width="1919" height="1025" alt="image" src="https://github.com/user-attachments/assets/3485b60f-c144-4220-b410-f2826090045e" /># 🩻 MediScan XR

An AI-powered web application for detecting **Pneumonia** from Chest X-Ray images using **Deep Learning** and **Flask**.

MediScan XR allows users to upload chest X-ray images and receive instant AI-based predictions indicating whether the patient may have **Pneumonia** or is **Normal**.

---

# 🚀 Features

✅ AI-Based Pneumonia Detection  
✅ Upload Chest X-Ray Images  
✅ Instant Prediction Results  
✅ Deep Learning Powered  
✅ Flask Web Application  
✅ Responsive Professional UI  
✅ TensorFlow + Keras Model  
✅ Real-Time Image Preview

⚙️ Installation Guide
1️⃣ Clone Repository
git clone https://github.com/augsatr/MediScan-XR.git

2️⃣ Open Project Folder
cd MediScan-XR

3️⃣ Create Virtual Environment
python -m venv venv

4️⃣ Activate Virtual Environment
venv\Scripts\activate

5️⃣ Install Dependencies
pip install tensorflow flask pillow numpy

▶️ Run Application
python main.py
or
http://127.0.0.1:5000

🧪 Model Training
To train the AI model:
python train.py

The trained model will automatically save inside:
models/pneumonia_model.h5
