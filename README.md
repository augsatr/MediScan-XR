## 🚀 Project Overview

MediScan-XR is an AI-powered medical imaging web application designed to detect **Pneumonia** from chest X-ray images using Deep Learning.

The system allows users to upload chest X-ray images and receive instant AI-based predictions through a clean and professional web interface.

This project combines:
- 🧠 Deep Learning
- 🩻 Medical Imaging
- 🌐 Flask Web Development
- 🤖 Artificial Intelligence

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/augsatr/MediScan-XR.git
```

---

## 2️⃣ Open Project Folder

```bash
cd MediScan-XR
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 4️⃣ Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

---

## 5️⃣ Install Dependencies

```bash
pip install flask tensorflow keras numpy pillow opencv-python
```

---

## 6️⃣ Run Application

```bash
python main.py
```

---

## 7️⃣ Open Browser

```bash
http://127.0.0.1:5000
```
